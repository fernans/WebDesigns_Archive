# WebDesigns

Collection of **static websites made independently as personal commissions/projects**, each one
kept complete with its development material, sketches and production files. They come from the
early 2000s era and several use **Macromedia Flash** (abandonware today) with Dreamweaver sources
(`.fla`, `.psd`, bocetos, etc.).

Sites included (accessible live via GitHub Pages from the folder menu of
[index.html](index.html)):

| Web | Description | Entry page |
|---|---|---|
| antonio salvador estilistas | Styling/hairdresser web | `antonio salvador estilistas/web/index.html` |
| COSMAVI | Cosmetic industry corporate web | `COSMAVI/index.htm` |
| DePalacioFilms | Film/animation studio, Flash content | `DePalacioFilms/` (reciclART.swf) |
| garciaibanez | Education/training portal | `garciaibanez/portal/produccion/index.html` |
| magan agencies | Model/talent agency | `magan agencies/web/index.htm` |
| mahecar | Bocetos only (web is a zip: `mahecar_web.zip`) | — |
| pedrorodriguez | Jeweller's web | `pedrorodriguez/web/index.htm` |
| PIGMEOS | Big Flash web project (full production "biblia" docs in `ANEXA`, published version in `_old_web/flash/rel`) | `PIGMEOS/_old_web/flash/rel/index.html` |
| RADIO COLOR | Sketches/bocetos (discman, chillout) | `RADIO COLOR/BOCETOS/enviar/chillout.html` |
| sergigamez | Games development personal web | `sergigamez/index.htm` |

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

For security reasons, some parts of the project may have been edited or removed; files larger than
100 MB (the hard GitHub limit) are not included (they are listed in `.gitignore`). Everything else
is published "as-is", including development material and bocetos as requested.

## Requirements / How to run

- Static content only: open the main [index.html](index.html) of the repository (GitHub Pages) and
  browse to each site, or open each site's `index.html` directly.
- Some pages need a web server (e.g. `python -m SimpleHTTPServer`) or the modernisation of Flash
  content — which today requires historic players (abandonware).
